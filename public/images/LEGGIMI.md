# Photos du site

Photos choisies par Andrea (brief du 28/11/2026), converties en WebP (largeur max. 900 à 1920 px, < 160 Ko).
Les chemins et les points de cadrage (`position` = object-position) sont dans `src/app/core/config/site.config.ts`
(bloc `images`) et, pour les services, dans `src/app/core/content/site-content.ts` (champ `image`).
Les textes alternatifs sont dans les dictionnaires (`photos`) et, pour les services, dans `site-content.ts` /
`content-texts.ts` (`imageAlt`).
